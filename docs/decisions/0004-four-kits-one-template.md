# 0004 Four visual kits, one lab template

**Status:** accepted (2026-10-12)

| Option | Pro | Con |
|---|---|---|
| Custom visual per topic | each one perfect | 20 topics = 20 mini-apps |
| One universal engine | build once | replication lag doesn't fit "dots through boxes" |
| **4 kits + shared `KitModel` contract (pick)** | new lab ≈ data + text | some topics bend to fit |

Build each kit only when its first lab is built. See [kits-and-labs.md](../kits-and-labs.md).
